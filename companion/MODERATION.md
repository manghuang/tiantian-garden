# 内容检查与验收边界

2026-09-13，Cloudflare 的 DeepSeek 会话具备文字输入/输出检查，默认 OpenAI WebSocket 会话也已增加播放前的回答文字检查。使用 OpenAI Moderations，不增加前端密钥，也不允许浏览器关闭检查。服务选择和麦克风确认页分别说明输入及回答文字的接收方与用途。

## 当前链路

1. 文字输入，或 OpenAI 从麦克风 PCM 转写出的文字。
2. 基础本地关怀/隐私规则命中时直接使用预设回复；原始敏感输入不进入 DeepSeek 或后续历史。
3. 其他输入先调用 OpenAI 文字检查。标记内容使用预设回复；自伤意图、暴力或涉及未成年人的性内容标记转为平静的寻求可信赖大人帮助的回复。
4. 检查通过后将本轮文字和服务器持有的短历史交给 DeepSeek。
5. DeepSeek 的回答在显示字幕、执行动作或提交语音合成之前再次检查。被标记时替换为预设安全话题；不把被拒绝的原文保留到后续上下文。
6. 通过检查的回答或预设回复才进入字幕、动作和朗读。

固定问候和人工编写的关怀回复直接使用，不对同一预设文案每轮调用审核。模型输出检查关注回答文字，不把动作名、提示词、音频或整段历史发送到检查接口。

`shared/moderation.js` 使用固定官方端点和 `omni-moderation-latest`，输入最多 500 字，结果最多 16 KB，等待最多 8 秒。检查 `flagged` 和类别布尔值，不自行猜测置信度阈值。缺少字段、非 JSON、超限、服务错误或取消均停止本轮，不静默跳过检查。服务错误正文、类别得分和密钥不返回浏览器。

## OpenAI Realtime 输出检查

`shared/reviewed-relay.js` 包装原有控制协议。音频、最终字幕和动作先保留在服务器内存；收到完整回答后检查合并的文字，通过后才将该回答发给浏览器。只包含动作工具调用的回合会把动作留给下一段通过检查的语音；不提前执行动作或显示字幕增量。

检查不通过、接口失败、音频/字幕缺失或超限时关闭会话，不把未检查的回答交给本机朗读，也不自动改走旧 WebRTC。关闭会话同时停止浏览器麦克风，并清除应用内上下文。用户可以换个话题重新开始。

插话和手动打断会中止审核、清除未放行的音频，并把这些音频在 Realtime 上游的已听时长截断为零；迟到的审核结果不能恢复旧语音。已放行并播放的音频仍使用原有实际听到位置报告。最多保留三条待处理回答，整个连接暂存音频不超过 30 秒 PCM，审核等待最多约 9 秒。

此方式要等短回答生成完成并检查后才播放，增加了首音等待；保留边听边检测说话、取消和插话。需要用真实账号记录首音延迟与总延迟，不能据此声称已满足实时体验指标。检查的是模型提供的语音文字稿，无法保证它与所有声音内容完全一致，尚未对输入音频或转写文字进行生成前拦截。

## 已验证和未验证

- 101 项单元/接口测试通过，包含 DeepSeek 审核和 Realtime 输出暂存、工具接续、取消、异常、超限、超时与播放顺序。测试验证应用的控制流程，不能证明模型检测准确率。
- 真实本地 workerd 额外验证审核不通过的模拟回答不会穿透 WebSocket 到达字幕/动作/合成，安全替代回复仍能生成音频帧。上游为本地替身，没有上传用户音频或调用实际审核 API。
- DeepSeek + OpenAI 模式检查输入与输出；默认 OpenAI Realtime WebSocket 模式检查输出。仅配置 DeepSeek 的文字模式保留基础本地规则；Node 旧版和维护用 WebRTC 仍未接入此模块。
- Moderations 不是 4–8 岁内容分级器，不负责核验家长同意、个人信息检测、所有危险模仿、依赖诱导或事实准确性。转写错误也可能改变检查结果。还需中文儿童场景评测、误报/漏报评估、实际账号与延迟验收，以及补齐 Realtime 输入检查。继续保持 `CHILD_USE_ENABLED=false`。

接口依据：[OpenAI Moderation 文档](https://developers.openai.com/api/docs/guides/moderation)。
