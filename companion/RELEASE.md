## 模型生成与复核

2026-09-13 修复浏览器中双眼全白：Three.js ImageBitmapLoader 通过 `fetch(blob:)` 读取 GLB 内嵌贴图，原 CSP 仅在 `img-src` 放行 blob，导致虹膜加载失败。Node 与 Cloudflare 现在共用允许 `connect-src 'self' blob:` 的策略，其余来源限制保留。加载后检查两只眼睛的贴图，失败时显示提示而不展示缺失瞳孔的模型。已在本地 Cloudflare 页面确认正面、斜侧面、招手及小跳时虹膜与瞳孔可见；54 项测试、网页构建与 Worker dry-run 通过。此修复没有改写原模型、眼部几何或动画。

`assets/dog-balanced.glb` 是独立发布资产，原始 `output/Skye_Animated.glb` 保留。每个细毛网格按固定抽样保留 8% 完整毛束；主体减面限制误差，保留有多个骨骼权重的顶点。眼球、口腔和带形态键的网格不减面；动画关键帧与绑定矩阵不改写，导出后恢复原始节点 TRS/matrix，避免导出器近似单位变换带来的漂移。近距离细毛密度低于原模型。

修改原模型后，使用 `npm ci --include=dev`、`npm run model:build`、`npm run model:validate`、`npm test` 重新生成和验证，再构建网页。体积/面数/源文件哈希见 `assets/model-report.json`，验证结果与目标文件哈希见 `assets/model-validation.json`。生成工具使用 [glTF Transform](https://gltf-transform.dev/modules/core/classes/NodeIO) 和 Meshoptimizer；没有使用线上模型转换服务。

服务器默认选择轻量文件，可配置 `MODEL_QUALITY=full` 后重启使用原始精细模型。两条模型路由均执行访问控制。当前标准文件仍约 50 万三角面，尚未达到设计中 10–30 万的长期目标；没有用单次桌面帧率观察替代低端平板的温度、内存和持续帧率测试。

## 配置与运行

Cloudflare 本地体验使用根目录 `Start_Cloudflare.cmd`，读取 `companion/.dev.vars`，提供 DeepSeek 与服务器中转语音。当前目标平台的线上部署按 [CLOUDFLARE.md](CLOUDFLARE.md) 执行。

下面保留旧 Node/Docker 路径：`Start_Companion.cmd` 读取 `.env`，不提供 DeepSeek。设 `ACCESS_CODE` 可检查口令流程；仅 `DEPLOYMENT_MODE=private` 允许监听外网。生产启动必须使用构建产物，不能公开 Vite 开发服务器。

Docker 部署模板位于 `deploy/`，**尚未经 Docker 实机验证**。需装有 Docker Compose 的服务器、有使用权的域名，以及服务器对外开放 80/443。域名 A/AAAA 记录应指向该服务器，Caddy 自动配置 TLS。[Caddy HTTPS 文档](https://caddyserver.com/docs/quick-starts/https)

1. 将 `deploy/.env.example` 复制为 `deploy/.env`，填写域名、随机访问口令和服务端 API Key。口令可用 `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"` 在自己的终端生成；不要把密钥贴进聊天。
2. 在 `companion/deploy` 执行 `docker compose --env-file .env config --quiet`，再执行 `docker compose --env-file .env build`。
3. 执行 `docker compose --env-file .env up -d`，检查 `docker compose ps` 与 `/api/health`。不要用 `docker compose config` 的完整输出分享配置，其中可能包含密钥。
4. 在 HTTPS 页面检查：未登录不能建立语音；输入口令后可进入；两个浏览器会话隔离；退出后麦克风关闭；重新登录与刷新可恢复页面；再用成年人账号测试真实语音。
5. 上线前记录实际镜像摘要，保留上一版镜像和会话卷。更新前通知试用者会断开互动；使用 `docker compose stop garden` 等待正常关闭，再升级。回滚时使用留存镜像，继续挂载相同 leases 卷。不要删除带有待关闭会话的卷。

Compose 仅对外发布 Caddy 的 80/443，应用容器以非 root 用户和只读根文件系统运行，会话卷保存少量连接标识与截止时间。没有开启 HTTP 访问日志，服务日志也不记录语音、字幕或密钥。[Compose 服务配置](https://docs.docker.com/reference/compose-file/services/)

登录 Cookie 是 HttpOnly、SameSite=Strict，线上另外启用 Secure；后端只接受配置的 Host/Origin。防护设计参考 [Express 生产安全实践](https://expressjs.com/en/advanced/best-practice-security/)；访问控制代码仍需独立安全评审。

## 运维边界

- 当前仅支持一个应用实例；登录和限流存在内存中，重启后需重新登录。不得横向复制实例共享当前 JSON 日志。公众账号及多实例需要共享会话/限流存储。
- 每登录最多一个语音会话，全服务最多三个，计入连接中的请求。每登录每分钟最多五次建立尝试，登录入口全服务每分钟最多十次；这是受控试用的保守上限。
- 会话恢复文件只保存随机内部 id、供应商 call id、截止时间。启动时尝试关闭遗留调用；失败保留并每 30 秒重试，不能确认关闭时继续占用名额。
- 登录有效期八小时，退出立即撤销。更换口令并重启撤销全部旧登录。共享口令不证明儿童年龄或家长身份。
- 如果会话文件损坏，启动失败；如果写入失败，健康检查变为 503 并停止创建新连接。先修复存储并确认供应商会话状态，不要直接清空记录。
- 操作系统突然中断与“供应商已创建但本机尚未拿到标识”的时间窗口仍可能产生孤立会话；需要供应商预算限制、监控和实际故障演练。
- 保持 `CHILD_USE_ENABLED=false`，直到真实儿童服务要求完成。这个开关本身不会配置服务方数据保留、取得家长同意或完成内容安全验收。
